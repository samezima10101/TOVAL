# 常設タブの実装・検証記録

実施日: 2026-10-19（日本時間）。環境: Windows、Node 22.15.0 / npm 10.9.2、Expo SDK 57。

## 変更した動作と構成

ユーザー指示により、ホーム・メモリー・ログ・ショップを常設タブで切り替える構成へ変更した。ショップから別タブへの移動は「退店会話を読んでから切り替える」との回答に従う。

- `app/(tabs)/`へ4画面を移し、同フォルダの`_layout.tsx`にJavaScript Tabsを配置した。ラベルとアイコン、既存テーマの色・フォントを使う。
- ルートの`app/_layout.tsx`は`(tabs)`・timer・story・side-storyのStackとする。詳細画面の下にタブ画面を置けるよう、初期ルートを`(tabs)`に指定した。
- タイマーはホームから、ストーリーはタイマー完了・メモリーから、サイドストーリーはショップから開く。詳細画面はタブ外に置き、既存の完了・閉じる・戻る処理を維持する。
- ホームの既存ショートカットは`router.navigate`で同じタブへ移動する。タイマーや会話のpush／replaceは既存処理を使う。
- 共通フレームは4タブ表示中だけロゴ用フッターを隠し、タブバーが下端とSafe Areaを担当する。詳細画面は既存のフッターを維持する。メモリー・ログのホームへ戻るボタンを除き、ログにもタイトルを表示した。ショップのホームボタンは退店会話後の移動として残す。

`(tabs)`はURLに含まれないため、`/`・`/memory`・`/log`・`/shop`と詳細3画面のURLを維持する。BGMの割当・音量・保存済みオン／オフ設定は変更していない。Providerと共通プレイヤーはルートの同じ位置に残し、タブ切り替えによる作り直しを避けた。

## ショップの退出と再入店

タブ切り替えは画面を削除しないため、既存のusePreventRemoveだけでは退店会話を挟めない。[useShopTabExit](../../src/hooks/useShopTabExit.ts)のContextをタブレイアウトに設け、ショップが退出処理を登録する。タブのtabPressで現在画面がショップなら通常移動を止め、ショップの退出処理へ選択先のコールバックを渡す。

ショップは最初の退出先をrefに保持する。購入・告知の保存中、サイド再生への遷移中、退店処理中の追加操作は既存のbusy／replayingと退出先refで抑止する。退店会話を読了してclosedへ移り、既存の画面削除防止が解除された後のEffectで一度だけ移動する。ハンドラー登録前のタブ操作も退店会話を飛ばさないよう抑止する。

タブ画面は保持されるため、closedのショップへ再フォーカスしたときだけ退出先と退出済みフラグを解除し、最新の共有状態から入荷案内を取り直して挨拶を始める。共有状態の参照はLayoutEffectで更新し、フォーカス処理自体は共有状態の更新で再実行しない。保存結果の反映だけで再生の連打抑止が解除されたり、退出直前のclosedから挨拶へ戻ったりすることを避ける。サイド再生から戻った場合はclosedではないため、商品一覧を維持する。

保存キュー、保存成功後の業務状態確定、原文保全、ID、価格、保存形式、計測・報酬処理には変更なし。自動テストや新しい依存は追加していない。

制限下で起動した最初の開発サーバーはReact Native DevToolsの導入でフォールバックを報告し、マニフェスト取得もUnexpectedServerErrorとなった。このサーバーは停止した。同じコマンドを必要な権限で再起動し、上記マニフェストとiOS起動用バンドルの取得に成功した。UnexpectedServerError自体の内部原因は確定していない。動作中の開発サーバーはポート8081。

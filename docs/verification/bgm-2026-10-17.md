## 無音報告への対応（2026-10-17）

当時のユーザー報告: iPhoneで消音解除・BGMオンでも鳴らない。機種・iOS・Expo Go/開発ビルドの別・エラー表示は未取得。当時は不合格として調査したが、10/18のユーザー訂正でマナーモードが原因と判明。不具合による不合格を撤回した。以下の競合は原因候補として調べた記録であり、報告端末の無音原因ではない。

SDK 54指定URLの転送を再確認し、SDK 57 audio資料とローカルexpo-audio 57.0.5のiOS実装を参照した。ローカル実装のpauseは100ms後、playing状態でないプレイヤーの音声セッションを無効化する。既存フックは空プレイヤーにもpauseを呼び、replace直後に読み込み完了を待たずplayしていた。この競合とMetro配信音源の読み込みが原因候補。報告端末でこの原因を直接確定したものではない。

修正: require音源をexpo-assetでローカルへダウンロードし、replace後のisLoadedを確認してplay。空プレイヤーへの不要なpauseを除去。ダウンロード・読み込みは各15秒の上限とキャンセルを持ち、待機中の背景/オフ/遷移で古い要求を破棄。失敗時は既存バナーで再試行する。共通1プレイヤー、同一曲の継続、消音遵守、背景停止、音量0.3、保存形式、タイマーの条件は維持。

Node REPLで現行フックをメモリ内変換し、React・Asset・AudioPlayer・AppStateを手動操作可能な代替実装へ差し替えて、命令列を照合した。自動テストファイルは追加していない。ネイティブ再生・聴音の代わりにはしない。

| 操作 | 期待結果 | 実際の結果（代替実装のみ） |
| --- | --- | --- |
| 初期null→BGMオン、ダウンロードを保留 | まだ再生しない | mode→downloadだけ、playなし |
| ダウンロード完了、音源読み込みを保留 | ローカルURIへreplace、まだ再生しない | file URIでreplace、playなし |
| isLoaded通知 | 再生を開始 | playが1回、volume=0.3、loop=true、待機用リスナーを解除 |
| 同一音源で再描画 | 先頭へ戻さない | replace/playの追加なし |
| inactive→active | 停止後、同じ曲を再開 | pause→mode→play、replace追加なし |
| オフ→背景→復帰 | 再生しない | playing=false、play追加なし |
| 読み込み中にbackground→isLoaded | 背景で再生しない | playなし、待機用リスナー解除。active復帰でplay |
| status.errorを通知 | 停止してエラーを表示 | playing=false、既存の再試行メッセージへ更新 |
| ダウンロードと読み込みをそれぞれ保留し15.5秒待つ | 無応答を通知し待機を終了 | 両方ともエラー表示、playなし、待機用リスナーなし |
| 読み込みエラー→再試行→download/isLoaded完了 | 古い要求を再開せず新しい再生を開始 | ローカルURIへ再replace後playが1回、エラー解除、待機用リスナーなし |

修正後の`npm.cmd run lint`・`npm.cmd run typecheck`はexit 0（警告なし）。`npm.cmd run bundle:ios`もexit 0、1532モジュール・43アセット・3.3MB hbcを生成。`git diff --check`も成功。診断はネイティブ聴音の確認ではない。実機でのダウンロード失敗、無音復旧は未検証。iPhoneではJS全体をReload（Fast Refreshのみでなく）して、消音解除/BGMオンで確認し、オフ/オン・背景復帰・黒画面も再確認する。

## ショップ・サイドストーリーの無音設定（2026-10-18）

ユーザーの追加指示で`BGM_TRACKS.non={source:null}`を追加し、`/shop`・`/side-story`をnonへ割り当てた。他の5画面はdefault。既存の共通再生管理のnull判定で停止し、BGMオン/オフ保存値を変えず、曲のある画面へ戻れば同じ曲を再開する。保存形式・ネイティブ設定・音源ファイル・タイマー処理の変更なし。メニューやSEプレイヤーも追加していない。

設定とnull時の停止条件をソース確認。実機ではホーム→ショップ→サイド→ショップ→ホーム、ショップ/サイドで背景復帰、BGMオフで往復を確認する。期待結果はショップ/サイドで無音、ホームではオンなら曲の続きから再開し、オフなら無音維持。変更後の聴音操作は未検証。`node node_modules/eslint/bin/eslint.js src/config/audioSettings.ts`、`node node_modules/typescript/bin/tsc --noEmit`、`git diff --check`はすべてexit 0。

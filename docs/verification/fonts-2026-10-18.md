# UI-v3フォントの実装・検証記録

実施日: 2026-10-18（日本時間）。環境: Windows、Node 22.15.0 / npm 10.9.2、Expo SDK 57。

## 実装範囲

- ユーザー指定のFigma「UI-v3」を読み取り、Zen Kaku Gothic Newの4ウェイト、Bebas Neue、DotGothic16の計6ファイルを追加した。[書体・用途・配布元](../font-settings.md)を参照。
- 全7画面と既存UI部品・入力欄に明示的なフォント指定を追加した。カレンダー内部の月・曜日も指定した。各ウェイトのフォントを直接登録し、端末による疑似的な太字指定を外した。
- 起動時にローカルのフォントを読み込み、完了後に共有状態と画面をマウントする。失敗時は端末標準フォントで通知し、読み込みコンポーネントを再マウントして再試行できる。
- 文字サイズ・余白・画像・色等のデザイン反映、ツールバー・設定画面は対象外。保存データ・保存形式v10・会話ID・価格・計測・報酬の処理は変更していない。自動テストの追加・復元も行っていない。

# 共通UIの簡素化・検証記録

実施日: 2026-10-20（日本時間）。対象: 共通フレーム、タブレイアウト、タイマー・会話画面、メニュー。ユーザーの「削れるところを削って」という指示に基づく。作業開始時から存在する未コミット変更は保持し、その上で整理した。

## 変更内容

- `ScreenBackground`の画像定義・表示・コンテナーを`AppFrame`へ移し、元ファイルを削除。Stackの`screenLayout`からは`AppFrame`だけを呼ぶ。画像は引き続き各Stack画面の内側に置き、背景2種・cover・中央配置・タップ／読み上げ対象外の設定を維持する。
- 通常画面の上下Safe Areaは`AppFrame`のヘッダー・フッターに集約。タイマー・メイン／サイド会話の重複指定を削除する。タイマーは中間Viewとそのスタイルも削除し、本文のアクセシビリティ指定を残す。起動時の状態画面は`AppFrame`の外なので、`AppStartupGate`のSafeAreaViewを維持する。
- タブバーの`position: absolute`を削除し、本文の下に領域を確保する。下端Safe Areaは従来どおりロゴフッターが担当する。4タブの並び・色・アイコン・グラデーション・退店会話の処理を維持する。
- タブの手動探索を`expo-router/react-navigation`の`getFocusedRouteNameFromRoute`へ置換。各Stack画面が保持する選択中タブを参照し、状態未作成時のpathnameによる補完も残す。
- メニュー終了処理を`src/navigation/menu.ts`にまとめ、ヘッダーの×とメニュー内「戻る」から利用する。履歴があれば直前の画面へ、直接起動時はホームへ戻る。
- `BackButton`の未使用のホーム遷移・任意ラベルを削除し、必須のonPressと「戻る」表示に限定。読み上げも「戻る」とする。
- フッターの背景色の重複、単一ロゴ用の横並び指定、子のないImageのalignItemsを削除する。

フォント読み込み・保存状態のProvider、起動復旧、BGMプレイヤー、タイマー計測、会話の保存・購入・退出判定は変更していない。保存形式・ID・依存も変更していない。自動テストは追加・復元していない。

## 同日追加: ヘッダーの統合

ユーザーの「AppFrameとAppHeader同じにしちゃえば？」という指示に基づき、AppFrameからのみ利用していたAppHeaderのJSX・スタイルをAppFrameへ直接統合し、AppHeader.tsxを削除した。背景・ヘッダー・フッター・保存／BGMエラーバナーを1ファイルで確認できるようにし、専用のprops受け渡しをなくした。NTの表示と読み上げは同じ整形済み文字列を参照する。画像・レイアウト・文字サイズ・メニュー開閉・エラーの再試行・Safe Areaの設定値は維持した。

統合後はlint・typecheck・`git diff --check`がexit 0。app/・src/にAppHeaderの参照が残っていないことを確認した。iOS exportはHermesの実行権限を付けて成功し、1565 modules・54 assetsを`dist/ios`へ出力。背景2種・NTバッジ・ロゴ・フォントの同梱を出力一覧で確認した。上記の1566 modulesのiOS exportは統合前の結果として保持する。依存・設定の変更がないためdeps:check・doctorは今回再実行していない。自動テストは追加していない。iPhone実機での表示・操作は未実施。

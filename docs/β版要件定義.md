# **ベータ版要件定義**

**αから追加された点は太字**  
**追加された項目等は☆**

1. ## **システム・機能要件**

- **タイマー設定機能：**
  - タイマーの時間を設定する。
  - それぞれ5分ごと、1時間ごとに変更可能。
  - **5分未満は設定不可**
- タイマー機能：
  - タイマーを表示。
  - タイマーが０になると「終了」ボタンが有効となる。
  - タイマーが０になった後は延長時間を表示。
  - 「終了」ボタンを押すとタスク管理機能を起動。
- **トーク機能：**
  - ストーリー解放時・**イベント発生時**にアイコンを表示。
  - キャラクターの会話を再生する。
  - **文字送り**
  - **文字送り中にタップ→テキスト善表示**
  - **文字送り後にタップ→次のテキスト**
  - **選択肢の表示・選択による会話の分岐**
- タスク管理機能：
  - ユーザーが指定したタスクをホーム画面に表示。
  - タイマーを終了させると未完了→完了を表示  
    ＋タスクを完了した回数をカウント
  - タスクが完了した日の0時orタスク完了から24時間後に完了→未完了を表示
- メモリー機能：
  - ストーリーを見返すことができる。
    　タイトル、番号、解放日
- **☆ログ機能**
  - **カレンダー形式**
  - **タイマー起動時間、日記**
- **ストーリーシステム：**
  - タスクが未完了の時に解放できる。
  - 解放したストーリーはメモリー画面から見返すことができる
  - **選択肢によってストーリーが変化する。ただし、ストーリーの変化は他の話に影響せず、１話１話は独立している。**
  - **解放済みのストーリーは見返すことが可能。ただし、別の選択肢のストーリーを見る際はNTを用いて解放する必要がある。**
- **NTシステム：**
  - １秒１NTカウントされる。
- **☆イベントシステム：**
  - ある条件を満たすとトーク機能が起動する。
  - 場合によってNTの追加等も発生する。
  - ex) 長期間タスクを放置など

2. ## **画面・UI要件**

**【共通UI】**

- **ヘッダー：**
  - NT数
  - ユーザーの名前
- **フッター：**
  - アプリロゴ

**【画面】**

- **ホーム画面：**
  - タスク・完了／未完了
  - ストーリー画面遷移（キャラクター）
  - タイマーモーダル遷移
  - メモリー画面遷移
  - **ショップ画面遷移（扉）**
- タイマーモーダル：
  - タイマー時間設定
  - タイマー画面遷移
- タイマー画面：
  - 時刻表示
  - タスク表示
  - ホーム画面遷移
- **ストーリー画面：**
  - キャラクター
  - テキストウィンドウ
  - ↑タップで次のテキストに進む
  - **選択肢**  
    **解放ストーリー→通常表示**  
    **メモリー画面→解放選択肢・未開放選択肢（NT必要）**
- **メモリー画面：**
  - ストーリーカード一覧  
    タイトル・開放日・番号・再生ボタン
- **☆チュートリアル画面：**
  - **ストーリー画面→コーチマーク**
- **☆ショップ画面（実装なし）：**
  - **テキストボックスのみ**

3. ## **コンテンツ・データ要件**

- **ユーザーデータ:**
  - 名前
  - 解放ストーリー数
  - 解放日
  - **選択肢の解放・未開放**
  - NT数
- **内部データ:**
  - **ストーリーデータ：**  
     **メイン：全14話**  
     **イベント：数未定**
  - **立ち絵：枚数未定**
  - **背景：枚数未定**

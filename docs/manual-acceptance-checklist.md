### 計測・日付・保存（M04〜M20）

1. 10秒計測→背景／手動ロック／画面外20秒→復帰。同じsessionIdのまま不在時間を除外する。黒画面だけなら継続、黒画面中のロックでは停止。日記入力中は停止し、戻ると再計測する。
2. 停止／再開直前に保存失敗を指定し、通知・停止維持・再試行後も不加算であること。保存保留→背景へ移動→解除でも、古い保存結果で再開しないこと。正常停止を保存→再開→強制終了→20秒後起動でも不明時間は加えない。
3. 23:50開始→00:20終了なら、連続集中1800秒は開始日のログへ全量、完了日／日次解放は翌日。10分計測→10分停止→10分計測なら1200秒だけ加算する。終了後の日記入力中に翌日へ進んでも終了ボタンの完了日を保持する。
4. 時計を変える場合は検証端末の停止中／日記入力中に行い、自然な日跨ぎも別途確認する。開始情報は開始直後・停止・再開・再起動で一致する。
5. 同日2回と別日初回を完了し、毎回「NT += 実集中秒、完了+1、ログ+1」、同日初回のみ1話解放を照合。キャンセル・日記編集・閲覧だけでこれらを増やさない。全14話後も報酬／ログを継続する。

### ログ詳細・日記（M19/M20/M42）

1. 星空背景と透過カレンダー、白い年月／曜日／日付、正常完了日の星を確認。空日記・0分も星、キャンセルは星なし。日跨ぎの所属はlogDate。
2. 離れた3日（例10/20・10/29・11/2）と年末年始に記録を用意し、矢印が最も近い記録日へ進むこと。同日複数件は1日、空の日は飛ばし、両端の矢印は薄く無効。1日だけなら両方無効。空の日も詳細を開け、前後に記録があれば最寄りへ移動する。
3. 縦長フォルダ枠の上に「10月23日金曜日」形式の日付、下に前／CLOSE／次。日別合計と個別時間が一致し、開始9:05は「9時5分」、集中0秒／59分59秒／1時間を照合する。
4. 同日3件以上で最初の長文をスクロール後、2・3件目／末尾を編集。選んだ本文位置だけが入力へ変わり、他の時刻・MEMOを保つ。フォーカス・キーボード表示後に先頭へ戻らず、表示済みなら不要な移動をしない。
5. 空→1行→末尾改行→3行、折返し、改行削除で伸縮すること。長文は上限高から内部スクロールし、カーソルが枠・操作バー・キーボードに隠れないこと。日本語変換・予測候補・途中カーソル・置換・外付けキーボードも確認する。
6. ✕は保存せず原文へ戻す。OKは成功後だけ編集終了。編集／保存中は矢印とCLOSEを隠し、保存中は入力／✕／OKを無効にする。失敗時は原文・下書き・エラーを保持して再試行。取消／保存後に通常操作が戻り、別の日記へ下書きを混ぜない。

ヘッダーの三本線をタップし、直下に右寄せ・最大幅288の音声設定が開き、再タップで閉じること。パネル外（NT付近・画面本文・タブ・フッター）をタップして閉じ、同じタップで背後のボタンやタブが作動しないこと。パネル内の余白・スライダー・消音ボタン・内部スクロールでは閉じないこと。メニューに重複がなく、小型iPhone・拡大文字でもスライダーと44ポイント以上の消音ボタンを操作でき、長いエラーはパネル内でスクロールできること。閉じた状態の空きヘッダーは背後の操作を妨げない。BGM／SEそれぞれ47%→消音0%→閉じる／開く→解除47%と再起動後の0%保持・解除時の初期音量を確認する。画面移動で閉じること、保存失敗は対象だけ元へ戻り再試行できること、保留中に閉じて開いても追加操作できず、未保存ドラッグは閉じると保存値へ戻ることを確認する。開閉・消音ボタンではタブSEを鳴らさず、BGMの再生位置・タイマーの計測状態を変えないこと。

### 保存失敗・保留・破損時の操作

`d.failNextWrites(1)`はRepository経由の次の書込1回（初期化前の回復退避も含む）を失敗、0で解除。replaceRaw自身の手動退避・投入はこの対象外。`d.holdNextWrite()`は次のRepository保存を保留、`d.releaseWrite()`で解除。`await d.readRaw()`と`await d.readBackups()`で主キー／退避の原文を照合する。AppState保存が先に失敗を消費したら対象操作直前に再指定する。音量・設定はまず非計測状態で再現し、ライフサイクル競合はM15で分けて行う。

| 操作 | 失敗／保留中と再試行後の確認 |
| --- | --- |
| 完了／購入 | 基準NT180・完了1・日記1を保持。成功後だけ1回確定。第1話追加分岐60 NTなら成功120、再購入は追加消費なし。サイド102は第2話解放済みデータで確認 |
| 日記／名前 | 編集開始後に失敗指定。rawと元の表示保持、対象下書き・エラーから再試行し対象だけ更新。時間／NT／完了／権利は不変 |
| 音量 | 保存前に失敗指定→操作中プレビュー→指を離す→保存値へ表示／音を戻す→同じ希望値を再試行。0%を希望する場合も確認。保留中の追加操作抑止、対象以外の音量・原文を維持 |
| 連打／退出 | hold→無料選択／購入／完了／設定保存→閉じる／戻る／スワイプ／連打→release。単一保存・単一遷移、停止維持、希望値や下書きの混入なし。告知保存も確認 |
| 破損と初期化 | 不正データ投入／Reload→再読込／初期化確認キャンセルでも原文不変。初期化直前の失敗でも保持。明示的再試行成功時だけ別キーへ原文退避・照合して初期化。確認後に原文が変われば初期化拒否。復旧は保全コピーを修復して投入／全体Reload |

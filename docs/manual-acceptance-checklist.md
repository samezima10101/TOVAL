## 結果の記録方法

各ビルドの結果をこの一覧のコピー、または別の記録ファイルへ残す。「未実施／合格／不合格」を区別し、不合格は再現手順と修正後の再確認を残す。

| 記録項目 | 値 |
| --- | --- |
| 段階 | 未記入（仮素材の機能完成／正式素材の最終完成） |
| 実施日・実施者 | 未記入 |
| iPhone機種・iOS | 未記入 |
| アプリ版・ビルド番号・コミット | 未記入 |
| 入手方法 | 未記入（開発ビルド／TestFlight） |
| Node/npm・依存整備結果 | 未記入 |

実際の結果には、数値・保存前後の状態・再起動後の表示など、期待結果と比較できる内容を記録する。保存失敗・破損・旧データは検証用データと手順を使い、実利用の記録と分ける。開始時刻のない旧ログを新しい開始日へ推定移動しない。

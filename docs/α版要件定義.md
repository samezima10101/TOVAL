# **アルファ版要件定義**

1. ## **システム・機能要件**

- **タイマー設定機能：**
  - タイマーの時間を設定する。
  - それぞれ5分ごと、1時間ごとに変更可能。
  - デバッグのために0分でも設定可能。
- **タイマー機能：**
  - タイマーを表示。
  - タイマーが０になると「終了」ボタンが有効となる。
  - タイマーが０になった後は延長時間を表示。
  - 「終了」ボタンを押すとタスク管理機能を起動。
- **トーク機能：**
  - ストーリー解放時にアイコンを表示。
  - キャラクターの会話を再生する。
- **タスク管理機能：**
  - 管理するタスクは1件とする。
  - 初回設定時にユーザーがタスク名を指定できる。
  - 初回設定後もタスク名を編集できる。
  - ユーザーが指定したタスクをホーム画面に表示。
  - タイマーを終了させると未完了→完了を表示  
    ＋タスクを完了した回数をカウント
  - タスクが完了した日の翌日0時に完了→未完了を表示
- **メモリー機能：**
  - ストーリーを見返すことができる。
    　タイトル、番号、解放日
- **ストーリーシステム：**
  - その日の初回タスク完了時に限り、未解放の次のストーリーを1話解放する（1日1話まで）。
  - 解放したストーリーはメモリー画面から見返すことができる。
  - 全3話を解放した後も、タスク完了処理とNT獲得は継続する。
  - 全3話を解放済みの場合は「すべて解放済み」と表示する。
- **NTシステム：**
  - １秒１NTカウントされる。

2. ## **画面・UI要件**

**【共通UI】**

- **ヘッダー：**
  - NT数
- **フッター：**
  - アプリロゴ

**【画面】**

- **ホーム画面：**
  - タスク・完了／未完了
  - ストーリー画面遷移（キャラクター）
  - タイマーモーダル遷移
  - メモリー画面遷移
- **タイマーモーダル：**
  - タイマー時間設定
  - タイマー画面遷移
- **タイマー画面：**
  - 時刻表示
  - タスク表示
  - ホーム画面遷移
- **ストーリー画面：**
  - キャラクター
  - テキストウィンドウ
  - ↑タップで次のテキストに進む
- **メモリー画面：**
  - ストーリーカード一覧  
    タイトル・開放日・番号・再生ボタン

3. ## **コンテンツ・データ要件**

- **ユーザーデータ:**
  - 名前
  - 解放ストーリー数
  - 解放日
  - NT数
- **内部データ:**
  - ストーリーデータ：全3話×3テキスト（仮）
  - 立ち絵：合計4枚
  - 背景：枚数未定

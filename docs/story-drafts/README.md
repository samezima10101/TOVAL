## 共通の構成

各話を「共通前半→選択した分岐AまたはB→共通後半」で再生する。各話の選択はその話の中で完結し、別の話の本文に影響しない仮稿とした。再生・既読・NT解放の最終ルールは[完成基準](../completion-criteria.md)で確定する。

- 本文差し替え時は話ID・分岐IDと保存状態の関係を確認する。第1話の既存分岐IDは維持する。
- 価格とサイド会話の指定話読了条件は、本文とは別の編集用設定ファイルにまとめる。
- 仮稿は既存のnormal/talk表情で表現できる内容。正式立ち絵・Figma反映後に文字量・改行・選択肢のレイアウトを確認する。
- サイド会話3件はこの14話に含めない。

# My-June

My-June は、1件のタスクに集中するオフラインの Expo アプリです。Alpha のコア機能は実装済みで、現在は Beta のログ画面とショップ導線を作業中です。Beta は未完了です。

## 開発

```bash
npm install
npm run start
```

対象は Expo SDK 54 の iOS / Android（Expo Go）です。SDK 54 は React Native 0.81、React 19.1 を対象とし、Android 7+ / iOS 15.1+ が公式の最小環境です。

## 現在の実装状況

### Alpha コア（実装済み）

- タスクは1件。初回にタスク名を入力し、後から編集できます。
- タイマーの設定、カウント、予定時間到達後の終了、キャンセル、タイマーセッションの保存と再開を提供します。Alpha では0分から23時間55分まで、5分単位または1時間単位で設定できます。
- 予定時間前のキャンセルは報酬・完了・ストーリー解放を発生させず、正常終了時に1秒=1 NTで記録します。
- その日の初回完了時に次の1話だけ解放し、全3話解放後も完了とNT獲得を継続します。
- ストーリー再生と端末内メモリー、ホーム画面からの解放済みストーリーへの会話導線を提供します。
- 状態は `@react-native-async-storage/async-storage` のスキーマ付きスナップショット1件へ保存します。クラウド同期、通知、イベント、ショップ、複数タスクはAlphaの対象外です。

タイマーは実行区間をミリ秒単位で保存し、アプリが非アクティブまたはタイマー画面が全画面表示でない間は一時停止します。アプリがアクティブかつタイマー画面に戻った時だけ再開し、旧スキーマの実行中セッションは不明な経過時間を加算せず一時停止状態へ移行します。

ストーリー本文は `habit-test` の HEAD `c3eb5ab` にある `episode01.ts`〜`episode03.ts` と `StoryData.ts` のタイトルを、実行時依存なしの型付き静的データとして移植しています。既存の My-June の立ち絵4枚（Gem / Alta）へ表情を対応付けています。

### Beta 作業中

`main@e96af09` には次の画面作業が入っています。これらはBeta完成を意味しません。

- **ログ（`/log`）**: カレンダーと記録モーダルのUIシェルがあり、ホームから到達できます。現在は `app/log.tsx` 内の3日分のハードコードされたモックデータだけを表示し、アプリの完了記録や永続状態とは接続していません。
- **ショップ（`/shop`）**: ホームから到達できるプレースホルダーです。「立ち入り禁止」とホームへ戻る操作だけで、商品・購入・NT消費はまだありません。

### 主なBeta残課題

- ログを実際の完了記録・タイマー起動時間・日記へ接続し、永続化する。
- ショップの商品、購入、NT消費の仕様と画面を実装する。
- 文字送り、選択肢と分岐、イベント会話、追加ストーリーを実装する。
- Betaの5分未満設定不可、ユーザー名、チュートリアルなどAlphaとの差分を反映する。
- 非アクティブ／全画面表示外でのタイマー停止と、アクティブかつ全画面表示での再開を実機で確認する。

## 端末で確認する項目

初回入力と再起動後の保持、0分即終了、通常カウント、期限前キャンセル、期限後の延長、終了連打、同日複数完了、日付跨ぎ、3日分のストーリー解放、全話解放後の継続報酬、メモリー再生を iOS / Android 実機または Expo Go で確認してください。タイマーのアクティブ／非アクティブおよび全画面／全画面外での停止・再開は、要件に対する実装確認項目です。
